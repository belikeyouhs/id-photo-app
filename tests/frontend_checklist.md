# 前端手动验证清单

## 1. 上传流程

- [ ] **文件选择上传**
  - 点击上传区域，弹出文件选择对话框
  - 选择 JPEG 图片，上传成功并显示预览
  - 选择 PNG 图片，上传成功并显示预览
  - 选择非图片文件（如 .txt），显示格式错误提示

- [ ] **拖拽上传**
  - 拖拽图片到上传区域，显示拖拽视觉反馈
  - 释放鼠标，图片上传成功并显示预览
  - 拖拽非图片文件，显示格式错误提示

- [ ] **文件大小限制**
  - 上传超过 10MB 的文件，显示大小超限提示
  - 上传小于 10MB 的文件，正常处理

## 2. 参数切换

- [ ] **证件照尺寸**
  - 切换到"一寸"，参数正确传递
  - 切换到"二寸"，参数正确传递
  - 切换到"小一寸"，参数正确传递
  - 切换到"护照"，参数正确传递

- [ ] **背景颜色**
  - 选择"白色"背景，结果背景为白色
  - 选择"蓝色"背景，结果背景为蓝色
  - 选择"红色"背景，结果背景为红色

## 3. 结果展示

- [ ] **生成结果**
  - 点击"生成"按钮，显示加载状态
  - 生成完成后，显示处理后的证件照
  - 证件照尺寸符合所选规格
  - 背景颜色符合所选颜色

- [ ] **下载功能**
  - 点击"下载"按钮，浏览器开始下载
  - 下载的文件格式正确（JPEG/PNG）
  - 下载的图片质量清晰

## 4. 错误提示

- [ ] **网络错误**
  - 后端未启动时，显示连接错误提示
  - 网络超时时，显示超时提示

- [ ] **业务错误**
  - 上传无人脸图片，显示"未检测到人脸"提示
  - 错误提示文字清晰，用户能理解

## 5. 响应式布局

- [ ] **桌面端**（1920×1080）
  - 页面布局正常，各区域比例协调
  - 上传区域、参数面板、结果区域显示完整

- [ ] **平板端**（768×1024）
  - 布局自适应，无横向滚动条
  - 按钮和文字大小合适

- [ ] **移动端**（375×667）
  - 布局垂直堆叠，操作便捷
  - 上传区域足够大，易于点击

## 6. 浏览器兼容性

- [ ] Chrome 最新版
- [ ] Firefox 最新版
- [ ] Safari 最新版（如适用）
- [ ] Edge 最新版
